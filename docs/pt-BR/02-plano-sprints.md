# Plano inicial de Sprints

Duração prevista: 4 Sprints de 2 semanas (8 semanas).

| Sprint | Objetivo | Entregas principais |
|---|---|---|
| 1 | Fundação e planejamento | requisitos, casos de uso, Git Flow, schema inicial e API base |
| 2 | Core logístico | otimizador de rotas, alocação 3D, testes de mesa e regras de estoque |
| 3 | Operação e comércio | autenticação, pedidos, inventário, desktop e portal web |
| 4 | Integração e qualidade | relatórios, auditoria, backup/restore, testes de sistema e documentação |

## Definition of Done
- Código revisado e versionado.
- Testes relevantes executados e aprovados.
- Regras de negócio documentadas.
- Tratamento de erros implementado.
- Sem credenciais ou dados pessoais reais no repositório.
- Instruções de execução atualizadas.
